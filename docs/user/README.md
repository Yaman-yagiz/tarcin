The man pages `tarcin(1)` and `tarcin(5)` hold the same reference in
your terminal: `man tarcin`, `man 5 tarcin`.

tarcin is an unofficial client. WhatsApp's terms do not allow
unofficial clients, and an account that uses one can be restricted or
banned. Read the [FAQ](faq.md#is-my-account-at-risk) before you link
an account you cannot afford to lose.
