## Conventions

- All repository documentation is written in English.
- Use relative links between documents. Every new document must be
  linked from this index or from a section index.
- ADRs follow the [template](adr/template.md).
- User documentation (installation, configuration, keybindings) lives
  under `docs/user/`, and as man pages under `docs/man/`.
